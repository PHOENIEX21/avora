# AVORA V7.5 — Premium Product Experience

This release is a global UX pass focused on investor-facing polish and mobile-first usability.

## Changes
- Premium public landing page for students, parents, teachers and schools.
- Persistent six-destination mobile dock: Home, Learn, Practice, Tutor, Exam, Progress.
- Desktop navigation keeps the same core destinations.
- Mobile exam mode hides the app dock while an assessment is running so controls never overlap.
- Exam submit action is no longer fixed over content on mobile.
- Independent touch targets and spacing for buttons.
- Premium AVORA Tutor page with functional "Explain more simply" and "Show me visually" controls.
- Visible video/visual teaching surface with an interactive concept walkthrough placeholder.
- Purposeful motion with reduced-motion accessibility support.
- Existing V7.4 personalized learning home retained.
- No database migration required.

Keep `.env.local` from your current project. Run `npm install` if needed, then `npm run dev`.
