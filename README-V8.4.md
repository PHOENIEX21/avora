# AVORA V8.4 — Deep Teaching Foundation

This release expands the Tutor from short lesson panels into slower, example-led teaching.

## Academic research used as reference
- Learn Africa New Concept Mathematics JSS1 Teacher's Guide (official publisher PDF): used to understand the professional teaching pattern — objectives, definitions, board demonstration, examples, student participation, classwork and application. The guide is all-rights-reserved, so AVORA does not reproduce its prose/exercises.
- New Concept Mathematics JSS2/JSS3 teacher-guide previews were used only to verify scope/order such as JSS3 simultaneous linear equations; copyrighted question wording is not copied.
- Existing Siyavula Nigeria CC-BY Mathematics scope remains the reusable/open Mathematics source.
- English follows the same deep-teaching engine; official New Concept English JSS1 teacher-guide structure is used as pedagogical reference, while AVORA wording/examples remain original.

## Product changes
- Fixes direct Simultaneous Equations / Simultaneous Linear Equations routing into Algebra instead of allowing a blank lesson.
- Fixes direct textbook route for JSS3 Simultaneous Equations to Chapter 6.
- Adds a reusable deep worked-example bank with line-by-line reasoning.
- Simultaneous equations now has five deliberately different worked examples: immediate elimination, matching coefficients, multiplication before elimination, substitution, and a word problem.
- Adds richer example sequences for percentages, linear equations, English concord, speech sounds, and comprehension.
- Every rich worked example ends with a learner checkpoint; Tutor waits for the learner.
- Teaching pacing is slower, especially during worked examples.
- Generic topics still use the curriculum plan and reviewed questions; more deep example banks can be added without changing Tutor architecture.

No migration or seed is required for V8.4.
