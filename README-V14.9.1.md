# AVORA V14.9.1 — Tutor-Like NERDC Teaching UI

This refinement makes the depth of the V14.9 NERDC integration visible to learners instead of presenting it like a static digital textbook.

## Learner-facing changes
- Shows the exact NERDC September 2025 performance objectives before teaching starts.
- Adds expandable curriculum provenance: class, subject, theme, official topic, content, evaluation guide and source page(s).
- Keeps official NERDC topic/objective wording unchanged while AVORA may split a broad topic into smaller teaching sections.
- Adds a visible **AVORA IS TEACHING** dialogue layer for every teaching step, above the board.
- Adds one-tap interruptions: **Why?**, **Explain more simply**, and **Another example**. These use the current board step as context.
- Keeps the animated/progressive board, authored learner checkpoints, misconception teaching, guided practice and 15-question topic exercise.
- Improves the MCQ exercise presentation and labels answer explanations as AVORA Tutor feedback.
- An incorrect mastery-exercise response can send the learner back to full teaching rather than only showing the key.
- Voice teaching remains preserved but disabled by default. Written teaching remains the academic source of truth.

## Academic source
NERDC New Revised Basic Education Curriculum, September 2025, as integrated in V14.9.0 for JSS1/JSS2 Mathematics and English Language.
