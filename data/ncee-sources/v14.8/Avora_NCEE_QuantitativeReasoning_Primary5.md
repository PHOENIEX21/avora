# Avora Deep Teaching Standard — Quantitative Reasoning
## Primary 5 (NCEE Track)

*Note: Quantitative Reasoning is a pattern-recognition skill, not a body of facts. The "Deep Teaching Standard" here means making the underlying pattern-spotting LOGIC explicit for every puzzle type, with many varied examples — since fluency comes from repeated exposure to different disguises of the same core skills (arithmetic, sequencing, relationships).*

---

## Topic 1: Number Patterns and Sequences

**Step 1 — Establish the core method for ANY sequence puzzle: find the RULE connecting consecutive terms by testing simple operations first (add, subtract, multiply)**

**Worked Example 1 (simple addition pattern):**
2, 5, 8, 11, ___?
Test: 5−2=3, 8−5=3, 11−8=3 — consistent rule: add 3 each time. Next: 11+3=14.

**Worked Example 2 (multiplication pattern):**
3, 6, 12, 24, ___?
Test differences first: 6−3=3, 12−6=6, 24−12=12 — NOT constant, so addition isn't the rule. Test ratios instead: 6÷3=2, 12÷6=2, 24÷12=2 — consistent: multiply by 2 each time. Next: 24×2=48.

**Worked Example 3 (a trickier alternating pattern, testing beyond the first guess)**
1, 4, 2, 5, 3, 6, ___?
This doesn't fit a single simple add/multiply rule across ALL terms. Look for TWO interleaved patterns: positions 1,3,5 (1,2,3 — adding 1 each time) and positions 2,4,6 (4,5,6 — adding 1 each time). The 7th term continues the first pattern: 3+1=4.

**Practice Questions:**
1. Find the next number: 4, 8, 12, 16, ___?
2. Find the next number: 1, 3, 9, 27, ___? (test differences first, then ratios if differences don't work)
3. Find the next number: 20, 17, 14, 11, ___?
4. Find the missing number: 2, 4, 8, ___, 32 (test the rule using the numbers you DO have on both sides of the gap)

## Topic 2: Relationships Between Numbers

**Step 1 — Establish odd/even, factors, and multiples as tools for spotting relationships in puzzles**

**Worked Example:**
"Which number does not belong: 12, 18, 24, 25?" Test: 12,18,24 are all multiples of 6 (12=6×2, 18=6×3, 24=6×4), but 25 is not (25÷6 doesn't divide evenly). 25 is the odd one out.

**Practice Questions:**
1. Which number does not belong: 15, 20, 25, 27? (test what the others have in common first)
2. Which number does not belong: 8, 16, 24, 30? (hint: test multiples of a specific number)

## Topic 3: Simple Logical Number Puzzles

**Step 1 — Establish reading a puzzle's given rule CAREFULLY and applying it exactly, testing with the given example before solving the actual question**

**Worked Example:**
"If ☆ means 'add 3 then double,' find 4☆."
Apply step by step: 4+3=7, then double: 7×2=14. So 4☆=14.

**Practice Questions:**
1. If ◇ means "multiply by 2 then subtract 1," find 5◇.
2. If a rule says "double the number and add 5," and the result is 15, what was the original number? (work backwards: 15−5=10, then 10÷2=5)

## Topic 4: Word-Based Number Problems (Pattern Recognition)

**Worked Example:**
"A pattern of chairs is arranged: 1 chair in row 1, 3 chairs in row 2, 5 chairs in row 3. How many chairs in row 5?"
Pattern: odd numbers increasing by 2 each row (1,3,5,7,9...). Row 5 = 9 chairs.

**Practice Questions:**
1. A pattern of tiles: 2, 4, 6, 8... How many tiles in the 6th position?
2. A saving pattern: Week 1 save ₦100, Week 2 save ₦150, Week 3 save ₦200. If the pattern continues, how much is saved in Week 5?
