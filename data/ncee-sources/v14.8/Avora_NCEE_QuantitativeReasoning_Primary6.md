## Topic 1: Number Sequences (Full Range — Arithmetic, Geometric, Mixed-Rule)

**Worked Example (mixed-rule sequence, harder than Primary 5's single-rule patterns):**
1, 2, 4, 7, 11, ___?
Test differences: 2−1=1, 4−2=2, 7−4=3, 11−7=4 — the DIFFERENCES themselves increase by 1 each time. Next difference=5: 11+5=16.

**Practice Questions:**
1. Find the next number: 3, 6, 11, 18, 27, ___? (test the differences of the differences, as shown above)
2. Find the next number: 100, 50, 25, 12.5, ___?

## Topic 2: Relationships Disguised as Puzzles

**Worked Example:**
"If 3☆4=10 and 5☆2=12, find the rule and use it to find 6☆3."
Test candidate rules against BOTH examples before committing to one:
Try "a+b": 3+4=7 (not 10) — rejected immediately, since it fails the first example.
Try "2a+b": 2(3)+4=10 ✓ matches the first example. Check against the second: 2(5)+2=12 ✓ matches too! Since this rule fits BOTH given examples consistently, it's confirmed.
Apply to find 6☆3: 2(6)+3=15.

This is the real exam skill: test a candidate rule against ALL given examples before trusting it — a rule that only fits ONE example could easily be a coincidence, not the actual pattern.

**Practice Questions:**
1. If 2★3=8 and 4★1=6, test at least two candidate rules against BOTH examples before finding the one that fits consistently, then find 5★2.
2. If a rule states "double the first number and subtract the second," and 6◆2 uses this rule, find the result.

## Topic 3: Fractions/Decimals/Percentages in Reasoning Puzzles

**Worked Example:**
"If ⅓ of a number is 15, find the number." Reasoning: if ⅓ = 15, the whole number = 15×3 = 45.

**Practice Questions:**
1. If ¼ of a number is 12, find the number.
2. If 20% of a number is 8, find the number.

---

## Topic 4: Algebraic Reasoning Puzzles

**Worked Example:**
"I think of a number, double it, and add 5. The result is 17. Find the number." (2x+5=17 → 2x=12 → x=6)

**Practice Questions:**
1. A number is tripled and 4 is subtracted, giving 20. Find the number.

---

## Topic 5: Time, Speed, Measurement Reasoning

**Worked Example:**
"A car travels at 40km/h. How far does it travel in 45 minutes?" Convert 45 min to hours: 45/60=¾hr. Distance=speed×time=40×¾=30km.

**Practice Questions:**
1. A train travels at 80km/h for 30 minutes. Find the distance covered.

## Topic 6: Full NCEE-Style Timed Practice Set

1. Find the next number: 5, 10, 20, 40, ___?
2. If ☆ means "add 4 then multiply by 2," find 3☆.
3. If ⅖ of a number is 20, find the number.
4. A number doubled and increased by 3 gives 19. Find the number.
5. Find the odd one out: 16, 25, 36, 40 (test which are perfect squares).
