## Section A: Quantitative Reasoning (Q1-15)

**1.** Find the next number: 3, 6, 11, 18, 27, ___? A)38 B)36 C)37 D)40 *Ans:A. Differences increase by 1 more each time: 3,5,7,9,11 → 27+11=38.*
**2.** Find the next number: 100, 50, 25, 12.5, ___? A)6.25 B)0 C)12.5 D)25 *Ans:A. Each term halved.*
**3.** If 2★3=8 and 4★1=6, using the rule 2a+b, find 5★2. A)12 B)10 C)7 D)9 *Ans:A. 2(5)+2=12.*
**4.** If ¼ of a number is 12, find the number. A)48 B)3 C)16 D)36 *Ans:A.*
**5.** If 20% of a number is 8, find the number. A)40 B)16 C)1.6 D)160 *Ans:A. 8÷0.2=40.*
**6.** A number is tripled and 4 subtracted, giving 20. Find the number. A)8 B)24 C)16 D)6 *Ans:A.*
**7.** A car travels 40km/h for 45 minutes. Find the distance. A)30km B)45km C)40km D)27km *Ans:A. 45min=¾hr. 40×¾=30km.*
**8.** Find the odd one out: 16, 25, 36, 40 A)40 B)16 C)25 D)36 *Ans:A. Others are perfect squares (4²,5²,6²); 40 isn't.*
**9.** If ☆ means "add 4 then multiply by 2," find 3☆. A)14 B)10 C)11 D)20 *Ans:A. (3+4)×2=14.*
**10.** Find the missing number: 2, 4, 8, ___, 32 A)16 B)12 C)20 D)24 *Ans:A. Each ×2.*
**11.** Find the next number: 5, 10, 20, 40, ___? A)80 B)45 C)60 D)70 *Ans:A.*
**12.** Which number does not belong: 8, 16, 24, 30? A)30 B)8 C)16 D)24 *Ans:A. Others are multiples of 8.*
**13.** A saving pattern: ₦100, ₦150, ₦200... Find Week 5's saving. A)₦300 B)₦250 C)₦350 D)₦400 *Ans:A. Add 50 each week: 100,150,200,250,300.*
**14.** If a rule says "double and add 5," and result=15, find the original number. A)5 B)10 C)7 D)20 *Ans:A. 15−5=10, 10÷2=5.*
**15.** Find the next number: 1, 4, 2, 5, 3, 6, ___? A)4 B)7 C)3 D)5 *Ans:A. Two interleaved +1 patterns; continues first sequence 1,2,3→4.*

## Section B: Verbal Reasoning (Q16-30)

**16.** Complete: "Finger is to Hand as Toe is to ___?" A)Foot B)Leg C)Nail D)Shoe *Ans:A.*
**17.** Complete: "Pen is to Write as Knife is to ___?" A)Cut B)Sharp C)Kitchen D)Metal *Ans:A.*
**18.** Find the odd one out: "Circle, Square, Triangle, Ball" A)Ball B)Circle C)Square D)Triangle *Ans:A. Others are 2D shape names.*
**19.** Complete: "Doctor is to Hospital as Teacher is to ___?" A)School B)Book C)Student D)Class *Ans:A.*
**20.** If CAT is coded as DBU (each letter +1), what is DOG coded as? A)EPH B)DPH C)EPG D)CNF *Ans:A.*
**21.** Find the odd one out: "Whisper, Shout, Elephant, Murmur" A)Elephant B)Whisper C)Shout D)Murmur *Ans:A. Others relate to volume of speech.*
**22.** Complete: "Author is to Novel as Composer is to ___?" A)Music B)Piano C)Song D)Band *Ans:A.*
**23.** Arrange logically: "He ate breakfast / He woke up / He brushed his teeth / He went to school" — what comes 2nd? A)He brushed his teeth B)He woke up C)He ate breakfast D)He went to school *Ans:A.*
**24.** Complete: "Kind is to Cruel as Brave is to ___?" A)Cowardly B)Strong C)Bold D)Fearless *Ans:A.*
**25.** Find the odd one out: "Novel, Poem, Play, Author" A)Author B)Novel C)Poem D)Play *Ans:A. Others are types of writing.*
**26.** Complete: "Rose is to Flower as Mango is to ___?" A)Fruit B)Tree C)Sweet D)Juice *Ans:A.*
**27.** Sort odd one: "Red, Blue, Green, Triangle" A)Triangle B)Red C)Blue D)Green *Ans:A. Others are colors.*
**28.** Complete: "Hand is to Glove as Foot is to ___?" A)Shoe B)Toe C)Sock D)Leg *Ans:A.*
**29.** Using "shift back by 2" (D→B, O→M, G→E means DOG→BME), decode "BME." A)DOG B)FOG C)DOT D)DOE *Ans:A.*
**30.** Complete: "Cold is to Ice as Hot is to ___?" A)Steam B)Fire C)Sun D)Warm *Ans:A.*
