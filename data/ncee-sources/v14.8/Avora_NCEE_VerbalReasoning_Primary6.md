# Avora Deep Teaching Standard — Verbal Reasoning
## Primary 6 (NCEE Exam Year)

---

## Topic 1: Word Analogies (Full Range)

**Step 1 — Categorize the DIFFERENT types of relationships analogies can use, testing each type explicitly**

- **Synonym-based:** "Happy is to Joyful as Sad is to ___?" → Unhappy/Sorrowful
- **Antonym-based:** "Hot is to Cold as Day is to ___?" → Night
- **Part-to-whole:** "Page is to Book as Brick is to ___?" → Wall/House
- **Function-based:** "Scissors is to Cut as Broom is to ___?" → Sweep
- **Category-based:** "Rose is to Flower as Lion is to ___?" → Animal

**Worked Example (identifying the relationship TYPE first, before answering):**
"Doctor is to Hospital as Teacher is to ___?" Relationship: a doctor WORKS IN a hospital. Apply: a teacher works in a ___? Answer: School.

**Practice Questions:**
1. Identify the relationship type, then complete: "Fish is to Water as Bird is to ___?"
2. Complete: "Author is to Book as Sculptor is to ___?"
3. Complete: "Kind is to Cruel as Brave is to ___?" (identify: synonym or antonym-based?)

## Topic 2: Odd-One-Out (Advanced)

**Worked Example (testing multiple possible groupings before settling on the intended one):**
"Triangle, Square, Circle, Pentagon" — test: number of sides. Triangle=3, Square=4, Pentagon=5 all have straight sides and a countable number of sides; Circle has NO straight sides/no countable sides. Odd one out: Circle.

**Practice Questions:**
1. Find the odd one out: "Novel, Poem, Play, Author" (three are TYPES of writing, one is a person).
2. Find the odd one out: "Swim, Run, Jump, Strong" (three are actions/verbs, one is a description/adjective).

## Topic 3: Coding and Decoding (Full)

**Worked Example (number coding, more complex than Primary 5's letter-shift):**
"If APPLE is coded as 12345 where A=1, P=2, P=2, L=3... wait — establish the actual rule: each DIFFERENT letter gets the NEXT available number in order of first appearance: A=1, P=2 (first P), P=2 (repeat, same number), L=3, E=4. So APPLE=12234."

**Practice Questions:**
1. Using the same "number letters in order of first appearance" rule, code the word "BANANA."
2. If a code shifts each letter BACK by 2 (so encoding D→B, O→M, G→E, meaning DOG becomes BME), decode "BME" by reversing the shift (moving each letter FORWARD by 2) to find the original word.

## Topic 4: Sentence and Word Sequencing

**Worked Example:**
Arrange in logical order: "He ate breakfast. / He woke up. / He brushed his teeth. / He went to school."
Correct order: He woke up → He brushed his teeth → He ate breakfast → He went to school (following the natural sequence of a morning routine).

**Practice Questions:**
1. Arrange in logical order: "The rain stopped. / Dark clouds gathered. / The sun came out. / It started raining."

## Topic 5: Word Classification and Grouping (Advanced)

**Practice Questions:**
1. Sort into two groups: "Whisper, Shout, Elephant, Mouse, Murmur, Giant" (hint: one group relates to VOLUME of sound/speech, the other to SIZE).

1. Complete: "Author is to Novel as Composer is to ___?"
2. Find the odd one out: "Run, Walk, Jump, Chair"
3. If a code shifts each letter forward by 3 (A→D), code the word "CAT" letter by letter (C→?, A→?, T→?).
4. Arrange logically: "Seed planted. / Flower blooms. / Plant grows. / Seed watered."
