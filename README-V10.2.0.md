This release extends the V10.1 Deep Teaching Architecture across the complete current AVORA JSS Mathematics + English teaching inventory.

- JSS1 Mathematics: 23/23 revised-2025 topics
- JSS2 Mathematics: 22/22 revised-2025 topics

Each map carries a governing idea, explicit internal forms/types, a minimum of three representative examples per mapped type, and no-unexplained-jump checks. The live curriculum Tutor adapter consumes these maps and exposes the mapped types/examples and no-jump contract in Tutor units.

## Teaching contract
AVORA must establish prerequisite language/concepts before relying on them; explain what, how and why; model the skill; contrast wrong/non-example cases; cover expected topic forms; guide practice; require independent production/application; and verify mastery. Productive English skills require production, not MC recognition alone.
