# AVORA V7.17 — Complete Topic Tutor + Exam Recovery

This release makes complete topic coverage a hard Tutor rule for BECE learning.

## Added
- Full BECE topic curriculum maps for Mathematics and English Language.
- Each topic is broken into required teaching sections with:
  - core meaning
  - key terms and definitions
  - clear explanation
  - worked example
  - section check
  - guided reviewed question
  - independent proof path
- Tutor now shows learner class level and target exam.
- One correct question is explicitly treated as one piece of evidence, not complete topic mastery.
- Exam results now create an ordered recovery path from weakest topics below 80%.
- Recovery path automatically guides the learner from one weak topic to the next after complete topic coverage.
- Voice Tutor reads the current curriculum section, examples and checks.
- Existing whiteboard, pause/repeat/slower, voice answer and independent-evidence rules remain intact.

## No database migration
Preserve `.env.local`. Existing V7.16/V7.15 database state is compatible.
