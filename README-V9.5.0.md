# AVORA V9.5.0 — JSS3 Mathematics Deep Checkpoint

This checkpoint adds dedicated, source-grounded deep teaching records for all 15 official JSS3 Mathematics curriculum entries already present in AVORA's NERDC inventory.

## Academic rule
NERDC controls curriculum scope and performance objectives. AVORA authors its own explanations, worked examples, guided practice, independent practice, misconception treatment, board-ready flow and mastery gates.

A topic is reconciled as `DEEP` only when its exact official topic ID has a dedicated deep lesson. This checkpoint does **not** claim English Studies is complete and does not end the final cross-class Mathematics reconciliation.

## JSS3 areas covered
- Numbers and Numeration: Whole Numbers; Rational and non-rational numbers
- Basic Operations: binary addition, subtraction, multiplication and division
- Algebraic Processes: Factorization; fractional equations; simultaneous linear equations
- Mensuration and Geometry: Similar Shapes; Trigonometry; Area of plane figures; Construction
- Everyday Statistics: Measures of central tendency; Data presentation

No database migration is required for this checkpoint.
