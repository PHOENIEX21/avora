# AVORA V9.1.0 — Academic Trust Foundation

This release changes AVORA's academic architecture from a collection of topic plans toward a curriculum-governed learning system.

## Added
- `lib/curriculumAuthority.ts`: authority/provenance hierarchy, JSS1–JSS3 Mathematics curriculum core graph, English official five-strand guard, and a strict deep-teaching contract.
- `lib/teachingBoard.ts`: structured universal teaching-board actions for Mathematics and English. AI may narrate/adapt pedagogy; AVORA owns the verified solution/action plan.
- `lib/examIntegrity.ts`: explicit AUTHENTIC vs AVORA_STANDARD identity plus cross-year exact/near-duplicate detection.
- `scripts/audit-academic-trust.mjs`: launch-blocking checks for provenance, curriculum classes, board capabilities, truthful English completeness status, and exam uniqueness policy.

## Source policy
1. NERDC official curriculum is the Nigerian curriculum authority.
2. Open/licensed materials can be adapted only under their actual licence.
3. New General Mathematics / Essential Mathematics may be used to cross-check scope, sequencing and pedagogy but copyrighted prose/questions are not silently copied.
4. Exam evidence informs weighting and recurring competencies.
5. AVORA authors its own explanations, examples, board lessons and AVORA-standard questions.

## Important honesty gate
V9.1.0 does NOT label JSS1–JSS3 English as fully complete. The official five-strand structure is guarded, but every official English performance objective must still be individually mapped before AVORA can truthfully claim 100% curriculum coverage. Mathematics now has a stronger class-by-class core graph and must continue to be reconciled objective-by-objective against the current official NERDC release.

No database migration. No seed required.
