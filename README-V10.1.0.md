# AVORA V10.1.0 — Deep Teaching Architecture

This checkpoint strengthens AVORA from curriculum-complete content toward teacher-complete instruction.

## New non-negotiable teaching contract

AVORA must not make unexplained academic jumps. Before a learner is expected to use a term, rule, operation or language structure, AVORA defines or verifies the prerequisite knowledge. Teaching now supports:

- key-term definitions before use;
- topic type / variation maps so one easy example cannot stand in for a complete topic;
- explicit reasons for meaningful transformations and rules;
- representative worked examples, including tempting alternatives that fail and why;
- guided practice before independent mastery;
- verification of answers and methods;
- board events that display both the expected topic types and the no-jump reasoning contract.

## Gold-standard factorisation lesson

JSS2/JSS3 factorisation is the first reference implementation. It establishes variable, coefficient, constant, term, factor, sum and product before factorisation; distinguishes expression `ax²+bx+c` from equation `ax²+bx+c=0`; teaches a=1 quadratic trinomials; adds the `ac` middle-term method for JSS3; verifies by expansion; and for JSS3 explains rearrangement and the zero-product principle before solving by factorisation.

This is a reference architecture, not a claim that every existing topic has already received full textbook-depth reconciliation. The next content phase must apply the same structure topic-by-topic to Mathematics and English and verify each expected subtype against reputable teaching references.
