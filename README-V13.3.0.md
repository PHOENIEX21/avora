# AVORA V13.3.0 — Family Seat, Class and Trial Enforcement

## Family seat rule
- Maximum: 3 learner identities per family.
- A learner who registered independently and is later linked to a parent becomes learner seat 1 of 3.
- That leaves exactly 2 additional learner seats.
- The parent account itself does not consume a learner seat.

## Class route
- Independent learner registration requires explicit class selection.
- Parent-created learners also require explicit class selection.
- Primary 5 / Primary 6 → NCEE path.
- JSS1 / JSS2 / JSS3 → JSS/BECE path.
- Class controls the learner's curriculum, Tutor, Practice and Exam route.

## Trial limits retained
- 14-day learner trial.
- 150 unique self-service assessment questions during the trial.
- JSS trial: 1 complete full mock.
- Primary/NCEE trial: 1 complete NCEE mock.
- Linking a learner to a parent/family does not restart the 14-day clock, question allowance, or full-mock allowance because all usage remains attached to the same learner identity.
