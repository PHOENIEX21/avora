# AVORA V9.0.4 — Concept-First Tutor Depth

This patch addresses two launch-blocking Tutor problems found in real mobile testing.

## What changed
- Concord now teaches the foundations before examples: noun, singular/plural noun, subject, verb, singular/plural verb, third-person singular agreement, `be`, `have`, `do`, true-subject detection, indefinite pronouns, compound subjects, collective nouns, measurements and relative clauses.
- Concord has multiple worked examples that explain *why* each form agrees, not just the final sentence.
- Geometry angle teaching now starts from angle meaning/classification and teaches straight-line, around-a-point, vertically-opposite and parallel-line relationships before testing them.
- The Tutor no longer prints a checkpoint question on the animated board and immediately repeats the same question in the answer card. The board now prepares the learner; the task appears once in the dedicated checkpoint.
- Existing aligned-practice, answer reveal, question explanation and mastery protections from V9.0.3 remain.

No database migration or seed is required.
