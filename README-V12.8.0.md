# AVORA V12.8.0 — Complete Supplied English Source Integration

This release overwrites V12.7 as the working base.

- JSS2 English First, Second and Third Terms
- JSS3 English First, Second and Third Terms

The six supplied files are not stored as passive references only. They are compiled into source-backed Tutor units, ordered teaching steps and learner-first checkpoints. They are reachable both through SOURCE COURSE term routes and mapped normal English topics.

The audit requires all 20 supplied curriculum documents, all 18 supplied term courses, all six new English files, exact meaningful-line representation for the six new files, and key high-risk concepts to exist in runtime.
