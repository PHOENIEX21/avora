# AVORA V7.20.6 — Live Teaching Board

Teacher-first Tutor rebuild.

## Changed
- Whiteboard now auto-progresses through teaching steps at a deliberately slower pace.
- Voice narration is separated from board notation: spoken scripts explain mathematics instead of reading symbols literally.
- Ratio & Proportion now teaches prerequisite units/conversions before using cm/m/kg/g examples.
- Final teaching step hands control to a real learner-response area instead of a dead Next button.
- Section coverage now requires an answer check; a wrong answer stays on the concept and offers re-teaching.
- Added persistent Ask AVORA area so students can interrupt the lesson, ask what a term means, ask why/how, or request another explanation/example.
- Tutor controls reduced to Pause, Replay, Speed, Voice and Ask AVORA.
- Mobile Tutor layout simplified for ~360px screens.
- Coverage remains separate from independent mastery evidence.

## Database
No migration or seed required.

## Important
Preserve `.env.local` when replacing your project.
